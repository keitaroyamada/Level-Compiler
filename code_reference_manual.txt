Level-Compiler Code Reference Manual
====================================

DATE: 2026-04-29
PURPOSE: コード全体を検索しやすく把握するための説明書。
FORMAT: `FILE:`, `DIR:`, `AREA:`, `SYMBOL:`, `IPC:`, `DOM:`, `TEST:`, `GUARDRAIL:` で検索できる索引形式。
SCOPE: main.js, main/, LC_modules/, preload/, renderer/, tests/, scripts/, resources/ の役割整理。
NOTE: この説明書作成ではアプリコードと LC_modules は変更していない。


Quick Search Keys
-----------------
KEY: FILE: 対象ファイルの役割。

KEY: AREA: 機能領域。
KEY: SYMBOL: クラス、関数、主要変数。
KEY: IPC: Electron IPC チャンネル。
KEY: PRELOAD_API: renderer から見える contextBridge API。
KEY: RENDERER: renderer 側の画面ロジック。
KEY: DOM: HTML の主要 DOM ID / class。
KEY: TEST: テストファイルと検証対象。
KEY: GUARDRAIL: 変更禁止・注意点。
KEY: SEARCH: 今後の検索機能で索引化しやすい対象。


Repository Overview
-------------------
DIR: root
ROLE: Electron デスクトップアプリのリポジトリ。
ENTRYPOINT: main.js
PACKAGE: package.json
APP_NAME: levelcompiler / Level-Compiler
APP_VERSION: 1.5.4
RUNTIME: Electron, Node.js, BrowserWindow, IPC, renderer JavaScript, p5.js
DOMAIN: stratigraphic correlation model, depth conversion, age model, plot, core image display, finder, divider, converter, labeler.

DIR: LC_modules
ROLE: ドメイン中核。相関モデル、年代モデル、プロットデータ、エンティティ、補助関数、Undo を保持。
GUARDRAIL: LC_modules は影響範囲が広い。明示承認なしに変更しない。

DIR: main
ROLE: main.js から切り出し途中の補助層。ウィンドウ定義、命名規約。

DIR: preload
ROLE: contextBridge で renderer に IPC API を公開する層。

DIR: renderer
ROLE: HTML/CSS/JS による各ウィンドウの UI。

DIR: renderer/js
ROLE: renderer 実装。main window は renderer.js。サブウィンドウは renderer_*.js。
GUARDRAIL: p5.min.js, msgpack.min.js など vendor/minified ファイルは通常編集しない。

DIR: tests
ROLE: CLI 回帰テスト、Playwright Electron E2E、テスト補助。

DIR: resources
ROLE: ツールアイコン、プロットアイコンなど静的リソース。

DIR: test_data
ROLE: サンプルモデル、画像、E2E/手動確認用データ。


Runtime Architecture
--------------------
AREA: Application boot
FILE: package.json
SYMBOL: main = main.js
SCRIPT: npm start -> electron .
SCRIPT: npm test -> node scripts/run-project-tests.js

SCRIPT: npm run test:e2e -> playwright test --config tests/playwright.config.js
SCRIPT: npm run build:win -> electron-builder --win --x64
SCRIPT: npm run build:mac -> electron-builder --mac --arm64

AREA: Main process
FILE: main.js
ROLE: アプリ起動、ウィンドウ管理、IPC、モデル読込/保存、画像処理、設定、アップデート、メニュー、Undo/Redo。

GUARDRAIL: main.js 内の計算、相関、年代、深度、シリアライズ処理は core logic 扱い。UI IPC 追加と混同しない。

AREA: Renderer process
FILE: renderer/js/renderer.js
ROLE: メイン画面。モデル描画、ツールバー操作、p5 canvas、右側 hole list、フッター、画像表示、plot 表示、編集 UI、E2E hooks。

RENDERER: p5Canvas は model view、p5penCanvas はペン、p5measureCanvas は計測、rasterCanvas は画像/スナップショット用途。

Main Data Flow
--------------
AREA: Load LC model
FLOW: renderer drag/drop or menu -> LCapi.RegisterLCmodel/RegisterModelFromCsv -> main.js handler -> LCCore.loadModelFromLcmodel/loadModelFromCsv -> renderer LCapi.LoadModelFromLCCore -> renderer.js loadModel -> #hole_list 更新 -> p5 redraw。

AREA: Load age model
FLOW: renderer -> LCapi.RegisterAgeFromCsv/RegisterAgeFromPath -> main.js RegistertAgeFromCsv -> LCAge.loadAgeFromCsv -> LCapi.LoadAgeFromLCAge -> AgeModelSelect 更新 -> renderer depth/age display 更新。

AREA: Load images
FLOW: renderer drag/drop/folder -> LCapi.RegisterCoreImage -> main.js RegisterCoreImage -> LCapi.LoadCoreImage -> renderer.js loadCoreImages/assignCoreImages -> modelImages cache -> p5Canvas/raster display。

AREA: Open Finder
FLOW: main toolbar #bt_finder -> LCapi.OpenFinder -> main.js OpenFinder -> finder BrowserWindow -> FinderApi.finderGetCoreList/depthConverter/MoveToHorizon。

AREA: Open Divider
FLOW: main toolbar #bt_divider -> LCapi.OpenDivider -> main.js OpenDivider -> divider BrowserWindow -> DividerApi.dividerConverter -> CSV export via dividerExport。

AREA: Open Plotter
FLOW: menu/window path in main.js -> plotter BrowserWindow -> PlotterApi.getPlotData/load -> PlotterApi.sendPlotOptions -> main renderer receives plot options -> renderer.js plot visibility/draw。

AREA: Edit model
FLOW: renderer context menu/edit mode -> LCapi.add/change/delete/connect APIs -> main.js edit IPC -> LCCore mutation -> UndoManager save state -> renderer reload/redraw。
GUARDRAIL: edit flow mutates model. Search should start with navigation/action discovery, not implicit mutation.

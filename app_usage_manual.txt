Application Overview
--------------------
USER_GUIDE: Level-Compiler は、複数の堆積物コアや層序セクションを同じ深度軸・年代軸上で管理し、相関モデルを作成・確認・変換するためのデスクトップアプリ。
USER_GUIDE: 主な目的は、Project、Hole、Section、Marker を使って相関モデルを組み立て、Composite depth、Event free depth、Age などの軸で確認すること。
USER_GUIDE: 画像、年代モデル、プロットデータを重ねて確認できる。
USER_GUIDE: Finder は指定深度や年代へ移動するための小窓。
USER_GUIDE: Divider はサンプリング位置をモデル上の深度へ再投影するための小窓。
USER_GUIDE: Converter は外部 CSV の深度・年代変換をまとめて行う小窓。
USER_GUIDE: Labeler はコア画像上でマーカーや位置情報を編集するための小窓。
USER_GUIDE: Plotter は外部データをモデル上にプロットするための小窓。

Basic Workflow
--------------
WORKFLOW: 最小基本手順
STEP: 1. 相関モデルを読み込む。
STEP: 2. 必要なら年代モデルを読み込む。
STEP: 3. 必要ならコア画像を読み込む。
STEP: 4. Y-axis を Drilling depth / Composite depth / Event free depth / Age から選んで表示を確認する。
STEP: 5. Finder で目的の深度・年代へ移動する。
STEP: 6. Grid、Labels、Connection、Event layer、Plot、Section images を必要に応じて表示切替する。
STEP: 7. 必要なら Divider / Converter / Labeler / Plotter を開く。
STEP: 8. 編集した場合は保存または export する。

Troubleshooting
---------------
USER_GUIDE: モデルが表示されない場合は、読み込み形式、ファイル名規約、右側 hole list の表示チェック、Y-axis、zoom 状態を確認する。
USER_GUIDE: Age が表示されない場合は、Age model が読み込まれているか、AgeModelSelect で選択されているか、モデルと年代データが対応しているか確認する。
USER_GUIDE: 画像が表示されない場合は、ImageSetSelect、画像フォルダ名、画像ファイル名、Section images 表示状態を確認する。
USER_GUIDE: Plot が表示されない場合は、Plotter 側の collection と series、depth scale、メイン toolbar の plot visibility を確認する。
USER_GUIDE: Finder/Converter で変換できない場合は、モデル外の値、未接続の範囲、Age model 未選択、列指定ミスを疑う。
USER_GUIDE: 表示が見づらい場合は、Zoom reset、Grid、Labels、Connection、Event layer、Plot、Images を切り替える。
